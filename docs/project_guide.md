# 서울 에어비앤비 가격 결정 요인 분석 로드맵 (Checklist)

> **프로젝트 목표**: 서울 에어비앤비 숙박 가격(`price`)을 결정하는 핵심 설명변수 규명 및 계량경제학적 다중회귀모형 구축  
> **데이터베이스**: `airbnb2.db` (총 1,955개 숙소, 19개 정규화 테이블 + `LISTING_BATCH`)  
> **분석 도구**: SQLite, Python, SAS  

---

## 📌 전체 진행 현황

| 단계 | 분석 영역 | 주요 산출물 | 상태 |
| :---: | :--- | :--- | :---: |
| **Phase 1** | 데이터 품질 검증 및 전처리 | 분석용 통합 마트 (`AIRBNB_ANALYTICS_MART`) | ⏳ 대기 |
| **Phase 2** | 피처 엔지니어링 (파생변수 생성) | 지리/호스트/어메니티/배치 파생변수 세트 | ⏳ 대기 |
| **Phase 3** | 탐색적 데이터 분석 (EDA) 및 가설검정 | 분포 진단, 독립표본 t-검정, 분산분석(ANOVA) | ⏳ 대기 |
| **Phase 4** | 다중회귀모형 구축 및 잔차 진단 | OLS 회귀식, 계수 해석, VIF 진단, 가정 검정 | ⏳ 대기 |
| **Phase 5** | 종합 결론 및 전략 보고서 작성 | 최종 분석 보고서 및 프레젠테이션 자료 | ⏳ 대기 |

## [Phase 1] 데이터 품질 검증 및 분석 마트 구축 (Data Quality & Mart ETL)

- [ ] **1-1. 결측치 구조 분석 및 처리 전략 수립**
  - [ ] 평점(`rating_overall`) 결측 176개 숙소 원인 규명 (신규 등록 숙소 여부 vs 비인기 숙소)
  - [ ] 결측 메커니즘 판별 (MCAR vs MAR vs MNAR)
  - [ ] 회귀분석 투입 전략 확정 (결측치 완전 제거 vs 신규 숙소 더미 변수 처리)
- [ ] **1-2. 가격 변수 이상치/극단값 정제**
  - [ ] `LISTING_PRICE` 단위 검증 및 이상치(극단적 고가/저가) 탐지 (Boxplot, IQR 기준)
  - [ ] 분석 타깃(종속변수) 확정: 1박 기본 가격(`price_amount`) vs 총 결제금액(`total_price_amount`)
- [ ] **1-3. 분석용 통합 플랫 테이블(Mart) 구축**
  - [ ] 정규화된 테이블(`LISTING`, `LISTING_PRICE`, `LISTING_RATING`, `HOST`, `LISTING_BATCH` 등)을 조인하여 단일 분석 테이블(`AIRBNB_ANALYTICS_MART`) 생성

---

## [Phase 2] 피처 엔지니어링 및 파생변수 생성 (Feature Engineering)

- [ ] **2-1. 공간·지리적 특성 변수 생성**
  - [ ] 좌표(`latitude`, `longitude`) 기반 서울 25개 자치구 매핑
  - [ ] 주요 도심(명동, 강남역, 홍대입구역)까지의 하버사인(Haversine) 최단 직선거리(km) 산출
- [ ] **2-2. 호스트 역량 및 운영 특성 변수 생성**
  - [ ] `is_multi_host`: 단일 숙소 호스트(0) vs 기업형/다숙소 호스트(1) 더미 변수
  - [ ] 호스트 활동 기간(개월수) 환산 (`time_as_host_years * 12 + time_as_host_months`)
  - [ ] `is_superhost`, 호스트 신원 인증(`is_verified`) 불리언 변수 정제
- [ ] **2-3. 크롤링 배치(코호트) 변수 결합**
  - [ ] `is_original`: 0814 확보 숙소(1) vs 0902 신규 유입 숙소(0)
  - [ ] 신규 유입 숙소의 가격 책정 성향(초기 저가 전략 등) 분석 변수로 활용
- [ ] **2-4. 편의시설(Amenity) 특성 추출**
  - [ ] 숙소별 총 편의시설 수(`amenity_count`) 산출
  - [ ] 핵심 프리미엄 편의시설(와이파이, 에어컨, 엘리베이터, 주차, 셀프체크인 등) 원핫 인코딩(Dummy)

---

## [Phase 3] 탐색적 데이터 분석(EDA) 및 통계적 가설검정 (EDA & Hypothesis Testing)

- [ ] **3-1. 종속변수(가격) 분포 검토 및 정규성 보정**
  - [ ] 가격의 왜도(Skewness) 및 첨도(Kurtosis) 수치 산출
  - [ ] 로그 변환 적용: $Y = \ln(\text{price})$ 타당성 검토 및 변환 전후 분포 비교
- [ ] **3-2. 집단 간 가격 차이 검정 (독립표본 t-검정)**
  - [ ] **가설 A**: 슈퍼호스트의 숙소는 일반 호스트보다 통계적으로 유의미하게 가격이 높은가?
  - [ ] **가설 B**: 전문(멀티) 호스트 숙소와 개인 호스트 숙소 간 유의미한 가격 차이가 존재하는가?
  - [ ] **가설 C**: 기존 등록 숙소(`is_original=1`)와 0902 신규 숙소(`is_original=0`) 간 가격 격차가 있는가?
  - [ ] Levene 등분산 검정 및 등분산/이분산 t-검정 수행
- [ ] **3-3. 입지별 가격 격차 검정 (일원분산분석 One-Way ANOVA)**
  - [ ] 주요 권역(강남권, 도심권, 마용성, 서북권 등) 간 평균 숙박비 분산분석
  - [ ] 집단 간 차이 발생 시 Tukey HSD 사후검정(Post-hoc) 수행

---

## [Phase 4] 계량경제학적 다중회귀분석 및 모형 진단 (Regression Modeling)

- [ ] **4-1. 다중공선성(Multicollinearity) 진단**
  - [ ] 독립변수 간 상관계수 행렬(Correlation Matrix) 확인
  - [ ] 분산팽창지수(VIF; Variance Inflation Factor) 측정 (기준: VIF > 10인 변수 조율/제거)
- [ ] **4-2. OLS 다중선형회귀모형 적합**
  - [ ] 기준 모형(기본 공간/숙소 스펙) vs 확장 모형(호스트 역량, 어메니티, 배치 추가) 비교
  - [ ] 모형 적합도 지표 확인: $R^2$, Adjusted $R^2$, F-통계량
  - [ ] 회귀계수($\beta$)의 통계적 유의성(p-value) 및 부호(방향성) 해석
- [ ] **4-3. 회귀모형 기본 가정 진단 (Model Diagnostics)**
  - [ ] 선형성(Linearity) 검정
  - [ ] 잔차의 독립성: Durbin-Watson 통계량 확인
  - [ ] 오차항의 등분산성: Breusch-Pagan / White Test
  - [ ] 오차항의 정규성: Q-Q Plot, Shapiro-Wilk Test
